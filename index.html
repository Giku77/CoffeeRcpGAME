규칙 예시(원하면 바꿔도 됨)
- 100% 맞춤: +1점 (완벽하다는 맛!)
- 일정 비율 맞춤: +0.5점 (음… 애매하네)
- 많이 틀림: +0점

재료/행동 선택 (클릭해서 내 레시피에 추가)

COUNTER
재료를 클릭하면 컵에 쌓여요.
CUP
READY
STACK
팁: 데이터가 “레시피 단계(문장)”라서, 여기선 재료를 단계 카드로 표현했어.
“얼마나 넣을건지”는 내 레시피에서 수정 눌러서 숫자만 바꿀 수 있어.

내 레시피

채점은 “정답 단계 순서”랑 비교해요.
순서/문구가 같을수록 점수를 줍니다.
결과 로그
예: 3이면 1~3잔 랜덤 주문

점수/채점 설정

“조금 틀리면 0.5점” 기준을 여기서 조정할 수 있어요.
기본 60초. 시간 초과 시 자동 서빙(=0점 처리)됩니다.
예: 0.6이면, 전체 단계 대비 맞춘 비율이 60% 이상이면 0.5점.

엑셀로 recipes 불러오기

엑셀(.xlsx)을 선택하면 자동으로 recipes를 갱신합니다.
컬럼 권장: id, name, question, hotSteps, icedSteps
hotSteps/icedSteps 셀에는 단계들을 줄바꿈 또는 | 로 구분해서 넣어줘.
